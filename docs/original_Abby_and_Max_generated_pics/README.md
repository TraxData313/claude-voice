# The original pictures

Abby and Max as they were first drawn, full size and uncropped. Everything else
in the repo that shows their faces comes from these two files:

- `docs/icons/<voice>-<size>.png` — the round icons, cropped and rimmed, used by
  the panel and as the window icon. Made by `docs/icons/make_icons.py`.
- `docs/art/<voice>.jpg` — 900px wide, for the README table and the pages at
  <https://traxdata313.github.io/claude-voice/>.
- `docs/banner.svg` — Abby, embedded in the banner.

They are kept here at full size so the derived copies can always be made again.
Both are original characters, the author's own, borrowed from nobody — the same
rule as the voices themselves. See [voices.md](../voices.md).
